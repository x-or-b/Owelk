# 다음 개발 묶음: 읽기 품질 → 라이브러리 본문 검색

## 이번에 구현한 범위

- 하단 패널 아이콘 클릭으로 열기/닫기, 우클릭 Left Dock / Right Dock. 패널 닫기 버튼·아이콘 드래그·Home 아이콘 제거.
- 항상 Home 시작, 이전 탭/레이아웃 보존, Continue Reading.
- 여러 탭과 독립된 읽기 상태, Ctrl/Cmd+W 닫기.
- 가로/세로 혼합 분할 트리, 크기 조절, 빈 그룹 제거, 전체 그룹 합치기.
- 탭 드래그로 그룹 이동·재정렬·가장자리 분할. 미리보기, 영역 밖 드롭/Esc 취소.
- 같은 논문을 별도 탭으로 복제해 비교. 백그라운드 탭은 상태만 유지.
- 기존 두 문서 세션을 버전 2로 변환. 기존 숨겨진 오른쪽 문서도 보존. 잘못된 레이아웃은 덮어쓰지 않음.
- Recent Papers에서 제거(원본·열린 탭 보존), 캡처 삭제 확인·로컬 휴지통.

위 기능은 자동 테스트를 통과한 개발용 구현입니다. 실제 장치 사용성·많은 논문 동시 사용 성능은 별도로 확인해야 합니다.

## 1. 읽기 품질 마무리

- 핀치 중 임시 화면 변환, 종료 후 선명하게 재렌더링. 손가락 중심점 유지, 연속 제스처, 선택 표시 정렬, 렌더 작업 누적 방지.
- 실사용 PDF와 여러 분할에서 초기 표시 지연·스크롤·선택 지연·메모리 측정. Home에서 불필요한 PDF 로드 지연도 줄일 것.
- 닫은 탭 다시 열기, 탭 탐색 단축키, 드래그 가장자리 자동 스크롤.
- 활성 그룹이 바깥 스크롤 영역 밖에 있을 때 자동으로 보이게 이동하는 UX.
- macOS 실기기 검증 이후 Windows/Linux 빌드·Ctrl+휠·Ctrl+W 검증.

완료 조건: 선택·캡처 좌표를 유지하면서 핀치가 연속적으로 보이고, 대표적인 큰 PDF/여러 분할에서 측정 결과를 남길 것.

## 2. 라이브러리 본문 검색

- 문서 ID와 경로를 분리하고 원본 지문·추출 버전을 기록.
- Qt PDF로 페이지별 텍스트 추출, SQLite FTS 인덱스를 백그라운드 생성. 진행 상태·취소·실패·재시작 처리.
- 검색 결과에 논문·페이지·일치 문맥을 표시하고 클릭하면 원문으로 이동.
- 문서 내부 검색과 라이브러리 전체 검색을 구별. 지금의 파일명/캡처 출처 검색도 유지.
- 2단 편집, 하이픈, 수식, 텍스트 없는 스캔 PDF를 구분해서 검증. OCR은 별도 범위.

완료 조건: 이름이 아니라 본문 문장으로 여러 논문을 찾고, 결과에서 정확한 페이지로 이동. 인덱싱 중에도 읽기·선택이 끊기지 않을 것.

## 3. 출처와 지식 관리

- 옮겨진 파일 재연결 UI: 후보 선택 → 해시 일치 확인 → 문서/탭/캡처 참조 일괄 갱신. 다른 버전은 자동 확정하지 않음.
- 텍스트 캡처, 영구 하이라이트, 짧은 노트, 캡처의 이름·태그·설명.
- 워크스페이스의 전체 연결 문서 목록, 연결 추가/제거, 이름 변경·삭제.
- 캡처 로컬 휴지통 복원·비우기 UI. 현재는 삭제 표식과 PNG가 보존되지만 UI 복원은 없음.
- 백업·내보내기는 사용자가 정한 v1 범위로 유지.

## 4. 이후

AI 읽기 보조와 웹 읽기. AI 제공자·인증은 실제 구현 시 지원 범위를 확인하고, 키 저장·외부 전송 범위·출처를 명확히 표시할 것. 현재는 API 호출·로그인·외부 업로드가 없습니다.

## 확인 방식

자동 테스트는 임시 데이터와 Qt offscreen 창에서 실행합니다. 컴퓨터 사용 MCP는 사용하지 않습니다. 실제 화면·마우스·트랙패드 사용성은 사용자가 직접 확인합니다. 네이티브 다중 창과 탭을 OS 창으로 떼어내기는 아직 범위 밖입니다.
