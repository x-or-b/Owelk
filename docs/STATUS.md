## 이번 Home 범위의 동작

- 복원할 문서가 없으면 Home 표시. 집 아이콘, 단축키, `/home`으로 이동.
- 기존 실제 저장 항목을 검색하고 클릭/Enter로 문서·캡처 원문·워크스페이스를 엶. 더미 목록 없음.
- Continue Reading과 Recent Papers에서 페이지·스크롤·배율 복원.
- 워크스페이스 생성, 빈 워크스페이스 진입, 다른 워크스페이스와 전환, 재실행 후 목록 보존.
- 하단 Files/Captures 아이콘 클릭으로 열고 닫기, 호버 설명, 하단 좌우로 드래그하여 패널 위치 변경. 표시줄 밖 드롭/Esc는 취소.

현재 워크스페이스는 기획서의 지식 컨테이너 전체가 아닙니다. 문서 연결을 기록하되 화면에는 최근 읽기 상태만 복원합니다. 캡처와 최근 논문 목록은 아직 앱 전체에서 공유됩니다. 복원하는 PDF는 최대 두 개이며 워크스페이스의 모든 연결 문서를 한꺼번에 여는 것은 아닙니다.

## 다음 개발 묶음

탭별 독립 상태 → 분할 트리 → 탭 드래그로 이동·분할. 기존 두 문서 세션과 워크스페이스 상태를 함께 마이그레이션해야 합니다. 상세 조건은 [NEXT.md](NEXT.md)에 기록했습니다. 그 후 통합 본문 검색·연결 관리·노트를 확장합니다.

## 확인 방식

빌드와 저장소/Qt offscreen 입력 테스트를 사용합니다. 실제 화면의 균형, 호버 설명, 장치별 드래그·핀치 감각은 사용자가 직접 확인합니다. 컴퓨터 사용 MCP로 화면을 조작하지 않습니다.
