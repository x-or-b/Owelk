# 기획서 대비 구현 현황

2026-09-21 기준. 현재는 **Home + PDF 탭·다중 분할 + 목차·썸네일 + 영역/텍스트 캡처 + 논문 본문 검색을 갖춘 개발용 리더**입니다. 기획서 장 번호가 순차적인 완료율을 뜻하지는 않습니다. macOS에서 빌드·자동 검증했고 Linux/Windows 실기기 검증은 남아 있습니다.

## 이번에 변경한 사용 방식

- PDF 스크롤바를 별도 16px 여백에 두고 문서 선택/캡처 입력과 분리했습니다. 기본 휠을 막던 범용 핸들러도 제거했습니다. 캡처 이동은 거리에 따른 700–1500ms InOutSine 스크롤 → 겹쳐 등장하는 OutBack 테두리 → 짧은 펄스 → 은은한 정적 테두리입니다. 수동 스크롤·확대·파일 전환은 이동 애니메이션을 중단합니다.
- Ctrl/Cmd+T 또는 탭 줄의 `+`로 실제 Home 탭을 추가합니다. 기존 PDF 위치는 유지하며 Home 탭 닫기·다시 열기·세션 복원을 지원합니다. 논문 제목 행은 진한 회색 배경/밝은 글자, 필터와 Current PDF는 높이 32px 회색 컨트롤로 통일했습니다. 회청색은 선택·포커스 포인트입니다. 더 보기에는 해당 파일명을 표시합니다.
- 캡처 카드의 Add/Edit note로 원문과 분리된 메모를 작성합니다. 명시적 저장, 검색·재실행 보존, 노트만 삭제, 미저장 편집 종료 보호를 제공합니다. [CAPTURE_NOTES.md](CAPTURE_NOTES.md).
- Home/Cmd+K 검색은 논문별 3개 미리보기, 논문 내 더 보기, 다음 결과 묶음, Back을 제공합니다. Filters에서 검색 대상과 논문을 제한할 수 있습니다. 실제 제목·저자·연도 검색은 아직 없습니다.
- 공백·한글이 포함된 PDF의 캡처 이동을 URL 동등성 비교로 수정했습니다. 이전 문자열 비교에서 동일 파일을 다르게 판단하던 실패를 재현한 뒤 수정했습니다.
- PDF 세로 스크롤바를 항상 표시하고 손잡이 드래그를 명시적으로 활성화했습니다. 가로 스크롤바도 드래그할 수 있습니다.
- 양쪽 패널과 본문 사이 경계를 드래그해 너비를 조절하고 저장합니다. 캡처 삭제 메뉴는 붉은색 Delete입니다.
- 이번 검증은 사용자 요청에 따라 해당 변경의 짧은 검사만 수행합니다. 실사용 확인: 기존 Paper B 캡처 클릭(같은 탭/다른 탭), 원문 위치·강조, 스크롤바 드래그, 양쪽 패널 크기 조절·재실행 보존.
- 빈 PDF 영역을 클릭하면 문장 선택을 해제합니다. 캡처 이동은 원본 URL·탭 ID에 묶고 기존 위치 복원을 기다리며, 탭 전환 시 남은 이동을 폐기합니다. 확대 상태의 가로 위치도 이동합니다.
- 명령 이름·검색 결과 제목/파일명·문맥의 일치 부분을 파란색과 굵기로 강조합니다. 실제 렌더 픽셀을 검사하는 회귀 테스트를 추가했습니다. 이전 CSS span은 Qt StyledText에 지원되지 않아 색이 보이지 않을 수 있었습니다.
- 선택 문장 → Save excerpt 또는 Capture: Save Selected Text → Captures에 저장합니다. 카드 클릭으로 출처 이동, 메뉴의 Read Excerpt… / Copy Text로 전체 읽기·복사, Home/Cmd+K에서 문장 내용을 검색합니다. [범위와 검증](TEXT_CAPTURES.md).
- 선택한 뒤 확대하거나 패널을 열어도 기존 선택의 텍스트·PDF 좌표를 유지합니다.
- 원본 재연결: 최근 파일/캡처 메뉴, Text index의 Locate…, 문서 오류 화면에서 진입 → 새 파일 선택 → Verify and Relink. 동일 파일만 허용하고 원본 파일은 수정하지 않습니다. [세부 동작](RELINK.md).
- Document의 선택된 Outline/Thumbnails 탭은 더 어두운 회색으로 표시합니다. 기능별 테스트 후 커밋합니다.
- Home/Cmd/Ctrl+K에서 열린 PDF 본문도 검색합니다. 단어 접두어 AND 검색, 관련도 순 최대 40페이지 결과이며 문맥·페이지를 표시합니다.
- Text index에서 진행·실패·일시정지·재시도를 관리합니다. 원본 변경 시 예전 결과의 이동을 차단합니다. [검색 범위와 한계](SEARCH.md)를 참고하세요.
- Files/Captures/Document 패널은 하단 아이콘으로 열고 닫습니다. 위치는 아이콘 우클릭 Left Dock / Right Dock. 별도 닫기 버튼과 아이콘 드래그는 제거했습니다.
- Document 패널에서 Outline/Thumbnails를 전환합니다. 내장 목차가 없는 PDF는 썸네일을 사용할 수 있고, 목차를 자동 생성하지는 않습니다.
- Ctrl/Cmd+K는 검색, Ctrl/Cmd+Shift+P는 명령입니다. 슬래시 입력 대신 읽기 쉬운 단일 이름을 사용하고 일치 부분을 강조합니다.
- 핀치 중 기존 래스터를 확대·축소하고 종료 후 선명하게 갱신합니다. 실제 입력감 확인은 남아 있습니다.
- Home 아이콘은 제거했고 매번 Home으로 시작합니다. 이전 탭을 버리는 것은 아닙니다. View → Home 또는 커맨드로도 돌아갈 수 있습니다.
- 최근 파일 제거는 목록에서만 제거하며 원본 PDF·열린 탭·캡처는 보존합니다. 실제 폴더 트리는 읽기 전용입니다.
- 캡처 삭제는 확인 후 목록·검색에서 제외하고 PNG를 앱의 로컬 휴지통으로 옮깁니다. 원본 PDF는 유지합니다.
- 탭 닫기는 Ctrl/Cmd+W, 탭 ×, 가운데 클릭, 우클릭 메뉴로 가능합니다. 마지막 탭을 닫으면 Home입니다.
- Ctrl/Cmd+Shift+T로 닫은 탭의 페이지·배율을 복원합니다. 현재 실행·워크스페이스의 최근 20개까지이며 디스크에 이 기록을 저장하지는 않습니다.
- 그룹 수의 고정 2개 제한은 없어졌습니다. 최소 문서 크기를 지키고 화면을 넘으면 바깥 작업 영역을 스크롤합니다.
- 가장자리 드롭은 이동해서 분할, 중앙 드롭은 그룹 이동, 탭 표시줄 드롭은 재정렬입니다. 같은 논문의 동시 비교는 명시적인 Duplicate to Split 명령을 사용합니다.

현재 워크스페이스는 기획서의 지식 컨테이너 전체가 아닙니다. 캡처·최근 논문 목록은 앱 전체에서 공유합니다. 워크스페이스의 연결 기록 전체와 현재 열린 탭 목록도 서로 다릅니다.

## 검증

저장소 테스트와 Qt offscreen UI 테스트로 기존 PDF 렌더링·선택·검색·캡처 회귀, 탭별 위치, 닫기·다시 열기, 혼합 분할·드래그, 세션 복원, Home 지연 로드, 삭제·원본 보존을 검사합니다. 분리된 팔레트 단축키·일치 강조·안전한 텍스트 처리, 중첩 목차·썸네일·문서 전환·빈 패널, 합성 네이티브 핀치 이벤트·중심점·해상도 유지도 검사합니다. [성능 기록](PERFORMANCE.md)은 합성 offscreen 기준이며 실제 장치의 디자인·입력감 확인을 대체하지 않습니다.
