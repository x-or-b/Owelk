# Capture notes

- 캡처 카드의 `Add note` / `Edit note` 또는 우클릭 메뉴로 엽니다. 텍스트·영역 캡처 모두 지원합니다.
- 원문은 읽기 전용으로 표시하고, 사용자 메모는 별도 `capture_notes` 테이블에 캡처 ID로 연결합니다. 원문 텍스트·PNG·좌표·SHA-256을 변경하지 않습니다.
- `Save`로 로컬 SQLite에 저장합니다. 최대 10,000자, 일반 텍스트이며 자동 저장·Markdown 렌더링은 아직 없습니다. `View source`는 편집 내용 저장에 성공한 다음 원문으로 이동합니다.
- `Cancel`은 편집 내용이 있으면 버리기 확인을 요청합니다. 저장 실패 때 편집기는 닫히지 않습니다. 미저장 편집이 있으면 앱 종료를 막고 저장/폐기를 안내합니다. OS 강제 종료 전의 미저장 초안까지 복구하지는 않습니다.
- 편집기는 패널이 아니라 메인 창에 속하므로 패널 이동·교체로 초안이 사라지지 않습니다.
- `Delete note`는 확인 후 노트 본문만 비웁니다. 노트 버전 이력/삭제 복원은 아직 없습니다. 캡처 자체를 휴지통으로 보내면 노트도 검색에서 숨기지만 DB의 노트는 보존합니다.
- Home / Cmd+K에서 노트 문장도 검색합니다. 결과에 `Note`를 표시하고 선택하면 편집기로 돌아갑니다. 기존 `Everything` / `Captures` 및 논문 범위 필터에 포함됩니다. 최대 20개의 노트 결과이며 별도 노트 전용 필터는 아직 없습니다.
- 워크스페이스별 문서·캡처 연결은 [관리 창](WORKSPACES.md)에서 편집합니다. 노트는 캡처에 속하므로 연결된 여러 워크스페이스에서 공유됩니다. 독립 노트, 태그, 영구 하이라이트는 후속입니다.

검증: 텍스트·영역 캡처 노트 저장/수정/삭제, 재실행 보존, 원문 분리, 검색 범위, 길이 제한, 유실/휴지통 캡처 저장 차단. Offscreen UI로 편집·검색 결과 열기·버리기 확인·종료 보호·패널 이동·삭제를 검사합니다. 실제 타이핑/크기/가독성은 사용자 확인이 필요합니다.
