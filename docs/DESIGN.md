# UI shape tokens

- 색·모서리·크기·글자 크기는 `Theme` 싱글턴(`src/ui/Theme.cpp`, QML `import Owelk.Ui`)이 정합니다. 테마는 시드 색 몇 개로 정의하고 나머지(호버·선택·보조 글자 등)는 시드에서 계산합니다. 모서리는 `radiusSmall 5`·`radius 7`·`radiusLarge 10`입니다.
- 앱 전체가 자체 Qt Quick Controls 스타일 `OwelkStyle`(`style/`, Basic을 기반으로 다시 그림)을 씁니다. QML 파일은 그냥 `Button`, `Menu`, `TextField`… 를 쓰면 같은 규칙이 적용됩니다.
- 상태 규칙(모든 컨트롤 공통): 호버 `Theme.hover` · 누름 `Theme.pressed` · 선택/켜짐 `Theme.selected` + `Theme.selectedText` · 키보드 포커스 `Theme.focus` 2px 테두리 · 주요 버튼(`primary`/`highlighted`, 대화상자의 확인 버튼) 강조색 채움 · 위험 동작은 빨간 글자.
- 모양: 컨트롤·카드 `radius`, 도구 버튼·메뉴 행·목록 행 `radiusSmall`, 메뉴·팝오버·대화상자 `radiusLarge`. 탭 막대(`TabBar`)는 세그먼트 컨트롤(트랙 안에서 현재 칸이 올라옴)입니다.
- 잘린 글자(`Label`의 elide)는 호버하면 전체가 툴팁으로 나옵니다(잘렸을 때만 동작). 메뉴는 가장 긴 항목만큼 넓어집니다. 스크롤바는 스크롤·호버 때만 보이는 얇은 둥근 손잡이입니다.
- 직접 그리는 탭·카드·패널·캡처 위치 테두리는 같은 토큰을 참조합니다. 앞으로 모서리 강도를 바꿀 때 개별 화면마다 숫자를 수정하지 않습니다.
- QML의 모든 색은 `Theme`의 이름 있는 토큰(텍스트·표면·컨트롤·테두리·스크롤바·주석 잉크)을 사용합니다. 화면 파일에 hex 값을 직접 쓰지 않습니다. 주석 잉크는 `Theme.annotationInks`와 C++ `ResearchStore::annotationColors()`가 같아야 하며 테스트로 확인합니다.
- 강조색은 Cmd+K에서 사용하는 파란색 계열로 통일합니다. `accent = #426b9a`(기본), `accentMuted = #829ab4`(은은한 테두리), `accentSurface = #d9dfe6`(선택 배경), `accentOnDark = #c5dcf5`(어두운 바탕의 강조), `accentText = #243e60`(제목)을 공통 토큰으로 사용합니다. 기본 표면은 회색, 삭제·오류는 빨간색을 유지합니다.
- 캡처 이동 후 위치 테두리는 `captureBorder = accent`의 단일 2px 선입니다. 주변 반투명 테두리/glow는 사용하지 않습니다. 스크롤 후 OutBack 등장·최대 강조까지 표시하고 완전히 페이드아웃합니다. `Theme.captureFadeDuration`(밀리초, `src/ui/Theme.h`)으로 시간을 조절하고 `qml/PdfCanvas.qml`의 `captureSpotlightFade`에서 곡선을 변경합니다. 정적 잔상은 남기지 않습니다.
- Cmd+K 검색 결과 선택은 배경색으로 표시하며 왼쪽 파란색 막대는 사용하지 않습니다. 검색어의 파란색 일치 강조는 유지합니다.
- 탭 × 버튼은 24×24px 정사각형을 탭 중앙에 배치하고 기본 배경은 탭과 같습니다. 호버/키보드 포커스 테두리는 `accent`로 표시합니다.
- PDF 페이지, 문장 선택 영역과 실제 캡처 좌표는 변경하지 않습니다. 스크롤바 손잡이, 얇은 구분선·선택 표시의 모양도 기존 용도를 유지합니다. 시스템이 그리는 파일 선택창·메뉴 등의 외형은 OS가 관리합니다.
- 패널 탭의 글자는 선택 여부와 관계없이 짙은 회색입니다. 빈 목차 안내문은 스크롤 콘텐츠가 아니라 패널의 실제 표시 영역 중앙에 배치합니다.
- PDF 상단바는 32px, 배율은 중앙, 우측은 주석 도구 | 영역 캡처 | ⋯ 순서이며 묶음 사이에 1px 구분선을 둡니다. 드물게 쓰는 동작(찾기·인쇄·내보내기)은 ⋯ 메뉴에 둡니다. 메뉴는 가장 긴 항목만큼 넓어집니다(최대 420px). 선택 도구는 선택 끝점 옆에 뜨며 화면 가장자리에서 안쪽으로 제한합니다. 표면은 회색·선택 강조는 파란색을 유지하되, 사용자가 고르는 주석 잉크에만 5색을 허용합니다.

검증: 공통 컨트롤/대화상자 기본 버튼 반경, 확인 버튼 동작, 캡처 테두리 색상·반경, 검색 필터 선택, 노트·워크스페이스 대화상자 동작을 Qt offscreen 환경에서 확인합니다. 실제 화면의 둥글기 체감은 사용자 확인이 필요합니다.

## 아이콘

- 아이콘은 Lucide(ISC 라이선스, `resources/icons/LICENSE`)에서 쓰는 것만 뽑은 글꼴 하나(약 21KB)입니다. Canvas로 그리지 않아 가볍고, 테마 색을 그대로 씁니다. `qml/Icon.qml`(글리프 하나), `qml/IconButton.qml`(아이콘 버튼)을 사용합니다.
- 아이콘 이름은 앱 의미 이름입니다(`close`, `add`, `more`, `copy`, `trash`, `ai`, `capture` …). 같은 뜻에는 같은 이름을 씁니다. 새 아이콘은 `tools/icons.py`의 목록에 추가하고 스크립트로 글꼴과 `qml/Icons.js`를 다시 만듭니다.
- 아이콘만 있는 버튼은 반드시 `description`을 가집니다(호버 설명, 500ms, 화면 낭독기 이름). 테스트(`tests/tst_icons.qml`)가 창 전체를 훑어 확인합니다.
- 글자를 유지하는 곳: 대화상자의 확인·취소, 화면의 주된 행동(Continue, Open PDF…, Open in Reader), 값 표시(배율 %).
- 주된 행동 하나(AI Send)는 둥근 강조색 버튼(`primary`)입니다.

## 목록·탭·칩

- 목록 행은 `ItemDelegate` 하나로 그립니다(호버·선택 공통). 내용 목록(Home의 최근 논문·워크스페이스, Library 논문·노트, AI 스레드)은 행 사이에 글자 시작 위치부터 연한 구분선(`separator`)이 있습니다. 사이드바 목록(Files, Library 사이드바, 목차)은 구분선이 없습니다.
- Home의 목록은 둥근 그룹 카드(`ListGroup`, `radiusLarge`) 안에 있습니다.
- 문서 탭은 막대 안의 둥근 알약 모양입니다. 현재 탭이 올라오고, 나머지는 호버 때만 바탕이 보입니다. 닫기 버튼은 현재 탭과 호버한 탭에만 보입니다. 탭에 호버하면 전체 제목과 경로가 나옵니다. 그룹에 속한 탭은 작은 강조색 점을 가집니다.
- 칩(`Chip`)은 검색 범위 필터, AI 모델·추론 강도, 탭 그룹에 같은 모양으로 씁니다. 켜진 칩은 선택 색입니다. 값을 고르는 칩은 오른쪽에 아래 화살표가 있습니다.
- 패널 머리: 패널이 하나면 이름, 여럿이면 아이콘 세그먼트입니다. Document 패널의 보기(목차·썸네일·연결·관련)도 아이콘 세그먼트입니다.
- 검색 결과에서 페이지를 묶는 논문은 어두운 막대가 아니라 굵은 제목 행입니다. 결과 종류는 색이 아니라 오른쪽의 작은 글자(p. 3, capture…)로 구분합니다.
- 글자 크기는 모두 `Theme.font*` 단계(캡션·작게·본문·소제목·제목)를 씁니다. 높이는 `controlHeight`·`rowHeight`·`barHeight` 등 크기 토큰을 씁니다. 글자 크기 설정을 바꾸면 컨트롤과 행 높이도 함께 바뀝니다.

## 호버와 우클릭

- 호버: 누를 수 있는 것은 모두 같은 호버 바탕을 보입니다. 아이콘 버튼은 설명을, 잘린 글자는 전체 글자를 툴팁으로 보여 줍니다(500ms).
- 우클릭: 대상마다 그 대상의 메뉴가 열립니다. 도구 버튼을 우클릭하면 그 도구의 옵션이 열립니다(형광펜·그리기 → 색).
- 메뉴 순서: 열기 | 그 대상의 동작 | 정리(태그·그룹·컬렉션) | 복사·내보내기 | 파일 | 위험한 동작(빨간 글자, 맨 끝, 확인 대화상자).
- 같은 대상은 어디서나 같은 메뉴입니다. 논문은 Home·Files·Library 모두 `PaperMenu` 하나를 씁니다(최근 목록에서만 "Remove from Recent Papers…"가 더해짐).
- 탭 메뉴는 탭 종류를 따릅니다: 웹(브라우저에서 열기·주소 복사), PDF(경로 복사·Finder에서 보기), 노트(Markdown 복사·휴지통). 이어서 분할, 그룹, 다른 탭 닫기·탭 닫기.
- 우클릭과 같은 내용을 띄우는 ⋯ 버튼은 두지 않습니다(캡처 카드·노트·웹 툴바·Home 워크스페이스에서 제거). 리더 상단바의 ⋯만 남깁니다(찾기·인쇄·내보내기·논문 정보처럼 위치와 무관한 동작). 페이지 우클릭 메뉴는 그 위치에 대한 동작만 담습니다.
