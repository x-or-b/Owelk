# Capture trash

- Captures 패널의 `Saved / Trash (N)`으로 저장 목록과 로컬 휴지통을 전환합니다. Trash에서 원문 텍스트/이미지 미리보기, 메모, 파일명, 페이지, 삭제 시간을 확인하고 `Restore`로 개별 복원합니다.
- 복원 후에는 Saved 목록과 Home/Cmd+K 검색에 다시 표시됩니다. Trash 화면은 유지하므로 여러 항목을 연속 복원할 수 있습니다. 복원된 항목을 열려면 Saved로 돌아갑니다.
- 기존 캡처 ID, PNG 픽셀, 텍스트, 좌표, 지문, 노트와 워크스페이스 연결을 유지합니다. 원본 PDF가 없어도 캡처를 복원할 수 있습니다. 원문 이동에는 기존 파일 검증·재연결 규칙을 그대로 적용합니다.
- 영역 캡처의 앱 생성 PNG만 `captures/trash/`에서 `captures/`로 이동합니다. 텍스트 캡처는 파일을 만들지 않고 삭제 표식만 제거합니다. 기존 파일을 덮어쓰거나 다른 PDF에 재연결하지 않습니다.
- 이미지 유실·읽기 실패·경로 충돌 시 복원을 중단하고 휴지통에 남깁니다. DB 실패 시 이동한 이미지를 휴지통으로 되돌립니다. 되돌리기까지 실패하면 보존된 이미지 경로를 알립니다. 파일 이동과 SQLite 변경은 하나의 OS 원자적 작업이 아니므로 그 사이의 강제 종료/디스크 오류 자동 복구는 아직 없습니다.
- Trash의 카드별 `Delete…`는 확인 후 해당 캡처를 영구 삭제합니다. 상단 `Empty Trash…`는 확인 후 휴지통의 모든 캡처를 영구 삭제합니다. 캡처 행·원문 텍스트·노트·워크스페이스 연결을 하나의 트랜잭션으로 지운 뒤, 커밋에 성공한 경우에만 `captures/trash/`의 앱 생성 PNG를 지웁니다. 지우지 못한 파일은 개수를 알리고 남겨 둡니다. 저장된(휴지통이 아닌) 캡처와 원본 PDF는 영구 삭제 대상이 아닙니다. 영구 삭제는 되돌릴 수 없습니다.
- 휴지통은 앱 데이터 안에 있으며 macOS 시스템 휴지통과 별개입니다. 자동 만료는 제공하지 않습니다.

검증: 영역 PNG 동일성, 텍스트/노트/원문 좌표 보존, 여러 워크스페이스 연결, 삭제·복원 후 재실행, 검색 재노출, 중복 복원 거부, 파일 유실/충돌/DB 실패 시 보존, Saved/Trash 전환·Restore 버튼, 개별 영구 삭제·전체 비우기(휴지통 항목만 삭제, 저장 캡처·원본 유지, 확인 창). 실제 확인은 캡처 삭제 → Trash → Restore → Saved → 원문 이동 순서로 진행합니다.
