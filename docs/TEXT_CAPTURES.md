# 텍스트 캡처

## 사용 흐름

1. 한 페이지 안에서 문장을 선택 → **Save excerpt**, 또는 Cmd/Ctrl+Shift+P → **Capture: Save Selected Text**.
2. Captures의 텍스트 카드 클릭 → 검증한 원문 페이지·선택 영역으로 이동.
3. 카드 `…` / 우클릭 → **Read Excerpt…**(전체 읽기), **Copy Text**(원문 전체 복사), 붉은색 **Delete**.
4. Home / Cmd/Ctrl+K → 저장한 문장으로 검색. 캡처 결과에도 문맥을 표시하고 일치 부분을 강조.

긴 문장의 카드 미리보기만 6줄로 제한합니다. 전체 읽기는 스크롤 가능하며, 메모 편집기가 아니라 읽기 전용 인용문입니다. HTML처럼 보이는 원문도 그대로 표시합니다.

## 저장과 안전장치

- 기존 `captures` 테이블은 그대로 유지합니다. 공통 출처에 PDF 경로·SHA-256·페이지·정규화한 경계 사각형을 저장합니다.
- 추가 `text_captures` 테이블은 capture ID로 연결하고, 추출한 문장·Qt PDF 문자 인덱스·가능한 경우 앞뒤 문맥(각 80자)을 보관합니다. 문자 인덱스는 추출기 의존 값이며, 해당 오프셋과 원문이 맞을 때만 문맥을 기록합니다.
- 공통 출처와 텍스트 행을 한 트랜잭션으로 기록합니다. 실패하면 둘 다 롤백하며, 텍스트 캡처는 PNG를 만들지 않습니다. 기존 영역 캡처 스키마에서 자동으로 추가 테이블을 생성합니다.
- 드래그 당시의 PDF 포인트 좌표와 텍스트를 고정합니다. 저장 작업에서 다시 추출한 선택이 화면의 인용과 일치해야 하고, 추출 전후 파일 지문도 같아야 저장합니다. 해시·추출은 작업 스레드에서 수행합니다.
- 캡처 열기는 기존 SHA-256 검증·동일 원본 재연결 흐름을 공유합니다. 원본이 없어져도 텍스트는 남고, 변경된 버전으로 자동 이동하지 않습니다.
- 삭제는 목록·검색·원문 이동에서 제외하는 표식입니다. 인용문·출처는 DB에 보존하고 원본 PDF는 수정하지 않습니다. 휴지통 복원 UI는 아직 없습니다.
- 전체 읽기 UI는 줄바꿈을 화면용으로 정규화할 수 있지만, 저장·Copy Text는 추출한 원문 그대로 사용합니다. 저장 데이터는 암호화하지 않습니다.

선택 경계와 문자 인덱스는 [Qt QPdfSelection API](https://doc.qt.io/qt-6/qpdfselection.html)를 사용합니다. 향후 추출기가 바뀌면 인덱스를 그대로 재해석하지 말고 원문·지문·좌표를 함께 확인해야 합니다.

## 현재 한계

- 단일 페이지의 선택 가능한 텍스트만 지원. 스캔 OCR, 암호 PDF 캡처, 여러 페이지 선택은 미지원.
- 2단 논문·수식·특수 폰트의 추출 순서를 교정하지 않습니다. 저장 후 인용 내용 확인이 필요합니다.
- 원문 이동은 260ms OutCubic 스크롤과 약간 겹치는 OutBack 테두리 등장(scale .9→1, opacity 0→1), 300ms의 한 번 펄스로 표시합니다. 이후 테두리는 정지하고 몇 초 뒤 opacity .4로 은은해집니다. 영구 저장 하이라이트·줄별 재강조와는 다릅니다. 파일 전환 때 제거하며 수동 스크롤은 이동 애니메이션을 취소합니다.
- PDF 본문·여백을 클릭하면 기존 문장 선택을 해제합니다. 드래그·스크롤이나 툴바의 Save excerpt/Copy 클릭은 선택 해제용 클릭으로 처리하지 않습니다.
- 캡처 문장은 대소문자 구분 없는 부분 문자열 검색, 최대 20개 결과입니다. PDF 본문 FTS의 단어 접두어 검색과 다릅니다. 의미 검색·AI 전송은 없습니다.
- 현재 캡처는 앱 전체 공유입니다. 메모·태그·워크스페이스 연결은 다음 단계입니다.
- 저장 요청은 최대 100,000자, 동시 대기 4개까지입니다.

## 검증

`text_captures` 테스트는 한 줄·여러 줄·역방향 선택, 원문 위치, 저장/재실행, 검색, 영역 캡처와 공존, 기존 DB 호환, 트랜잭션 롤백, 동일 파일 재연결, 변경/유실 원본 차단, 삭제 후 원문 보존을 검사합니다.

Qt offscreen UI 테스트는 실제 드래그 → Save excerpt / 명령 팔레트 → 자동 패널 열기 → 전체 읽기·복사 → 원문 이동·검색·삭제를 검사합니다. 선택 후 확대·패널 너비 변경, 이미 확대된 페이지 선택, 일반 텍스트 표시도 포함합니다.

실제 기기에서 확인할 것: 자주 읽는 논문의 여러 줄 선택 → Save excerpt → 전체 읽기/Copy Text의 내용 확인 → 재실행 후 검색·원문 이동. 자동 검증은 실제 PDF 추출 품질과 트랙패드 체감을 대신하지 않습니다.

## 캡처 이동 회귀 수정

- 2026-09-21: 공백·한글 파일명의 URL 문자열 표현 차이(공백과 `%20` 등) 때문에 같은 원본이 다른 파일로 판단되어 이동이 중단되는 문제를 재현했습니다. URL 자체의 동등성 비교로 교체했습니다. 같은 파일을 다시 여는 위치 복원 분기도 동일하게 수정했습니다. 공백 없는 파일만 사용한 이전 테스트의 빈틈을 보완했습니다.
- 이동을 예약할 때 원본 URL·탭 ID를 함께 묶고, 실행 직전 해당 탭/리더인지 다시 확인합니다. 지연 콜백이 그 순간 활성화된 다른 리더를 덮어쓰지 않습니다.
- 리더를 다른 탭에 재사용하거나 새 문서를 열면 이전 이동 예약을 취소합니다. 대기 중에도 URL이 바뀌면 폐기합니다.
- 이미 열린 PDF도 위치 복원이 끝난 다음 캡처 좌표로 이동합니다. 문서 내 검색의 자동 이동은 캡처 이동 전에 해제합니다.
- 같은 PDF를 여러 분할에 열었을 때는 현재 활성 복사본을 우선합니다.
- 확대 상태에서 가로로 화면 밖에 있는 캡처도 해당 영역이 보이도록 가로 스크롤을 이동합니다.
- 회귀 검사: 같은 문장을 가진 서로 다른 두 PDF, 이미 열린 원본의 다른 페이지로 이동, 복원 중 이동, 지연 실행 전 탭 전환, 다른 PDF 로드 후 남은 이동 예약 폐기. 단순히 한순간 목표 페이지가 되는지만 보지 않고 지연 후 위치·원본·강조가 유지되는지도 확인합니다.
