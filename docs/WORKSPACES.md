# Workspace links

## Open the manager

- Home의 Recent Workspaces 항목 오른쪽 `…`는 그 워크스페이스로 전환한 뒤 관리 창을 엽니다.
- 이름 있는 워크스페이스를 사용 중이면 하단 `Workspace…`로 현재 워크스페이스를 관리합니다.
- 임시 Local workspace는 관리 대상이 아닙니다. 먼저 Home의 Recent Workspaces 옆 `+`로 이름 있는 워크스페이스를 만듭니다.

## Documents and captures

- Documents는 현재 열린 탭이 아니라 전체 연결 문서 목록입니다. 탭을 닫아도 연결은 유지됩니다.
- `Link current PDF` / `Link PDF…`로 추가하고 `Unlink`로 연결만 해제합니다. 파일을 복사·삭제하지 않으며 열린 탭과 읽기 위치도 유지합니다. 추가한 PDF는 본문 검색 인덱싱 대상입니다.
- 읽기 중 새로 연 문서는 기존처럼 자동으로 연결됩니다. 명시적으로 Unlink한 문서는 열린 탭의 자동 저장이나 재실행으로 다시 연결되지 않습니다. 다시 연결하려면 Link를 선택합니다.
- Captures에서 앱에 저장된 캡처를 선택해 연결합니다. 같은 캡처를 여러 워크스페이스에 연결할 수 있습니다. 캡처의 원문 PDF 연결과 캡처 연결은 독립적입니다.
- 연결된 캡처의 Open은 검증된 원문 위치로 이동하며 Note는 캡처 노트를 엽니다. Unlink는 캡처/노트를 삭제하지 않습니다. 앱 전체 Captures 패널과 전체 검색의 범위는 바뀌지 않습니다.
- PDF 경로 재연결 시 연결 목록과 명시적 연결 해제 기록도 함께 갱신합니다.

## Rename and delete

- 이름 입력 후 Rename으로 저장합니다(1–120자).
- Delete workspace는 확인 후 목록/검색에서 숨깁니다. 저장된 레이아웃·연결 기록은 로컬 DB에 보관하며 현재 열린 탭은 Local workspace로 유지합니다.
- 원본 PDF, 캡처, 캡처 노트, 문서별 읽기 위치는 그대로입니다. 삭제한 워크스페이스를 다시 표시하는 UI는 아직 없습니다.
- 현재 세션에서 삭제한 워크스페이스 ID를 제거하는 작업은 삭제 표식 저장과 같은 트랜잭션으로 처리합니다. 뒤늦은 자동 저장이 삭제된 워크스페이스를 되살리지 않습니다.

## Verification and remaining work

임시 데이터에서 연결 추가·중복 방지·해제, 자동 저장 후 해제 유지, 다중 워크스페이스 캡처 연결, 이름 변경, 재실행 보존, 삭제 후 원문/노트/탭 보존을 검사합니다. PDF 재연결 뒤 연결 해제 유지도 검사합니다.

실사용 확인: Home → `…` → 문서 Unlink → 탭 유지 → Link → 캡처 연결/해제 → Rename → 재실행. 삭제는 시험용 워크스페이스에서 확인합니다. 실제 파일 선택 대화상자와 많은 항목의 사용성은 사용자 확인이 필요합니다.

후속: 캡처 휴지통 복원 UI, 워크스페이스 복원 UI, 검색의 워크스페이스 범위 필터, 관리 창의 대량 목록 검색. 백업/내보내기는 기존 v1 범위를 유지합니다.
