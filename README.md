# Owelk

개인과 동료의 논문 읽기를 위한 로컬 데스크톱 앱. 현재는 **macOS에서 검증 중인 개발용 프로토타입**이며, 기획서 전체가 구현된 상태는 아닙니다.

## 실행

기존 창을 닫은 뒤 프로젝트에서 다음 명령으로 실행합니다. 현재 수동 테스트 데이터와 읽던 위치를 그대로 사용합니다.

```sh
open -n /Users/gyu/Documents/Owelk/build/owelk.app --args --data-dir /Users/gyu/Documents/Owelk/build/manual-data
```

`--data-dir` 없이 실행하면 OS의 앱 데이터 폴더를 사용하므로, 위 테스트 데이터와 별도로 저장됩니다. 여러 인스턴스를 같은 데이터 폴더로 실행하지 마세요.

## 현재 기능

- Home: 중앙 검색, Continue Reading, Recent Workspaces, Recent Papers
- UI 모서리는 공통 5px이며, 캡처 원문 위치·탭 × 호버 테두리는 Cmd+K의 파란색 `#426b9a`입니다. [디자인 토큰](docs/DESIGN.md).
- 열린 PDF의 백그라운드 본문 인덱싱, 문맥·페이지 검색 결과, 원본 지문 검증 후 이동
- 옮겨진 원본 PDF 재연결: 동일 파일 검증 후 탭·읽기 위치·워크스페이스·캡처 참조 유지
- 이름 있는 읽기 워크스페이스 생성·전환 및 탭·분할·읽기 상태 저장
- 여러 PDF 탭, 탭별 독립 위치·배율, `⌘/Ctrl+T`로 새 Home 탭, `⌘/Ctrl+W`로 활성 탭 닫기
- 고정 2개 제한 없는 가로·세로 분할, 경계 드래그로 크기 조절, 탭 드래그 이동·분할
- `⌘/Ctrl+F`로 문서 내 검색창 열기, Esc 또는 ×로 닫기 (기본은 숨김)
- 마우스·트랙패드 문장 선택 및 복사, 줄 전체를 기준으로 높이를 고정한 선택 표시 (대문자·소문자·아래로 내려오는 글자를 추가해도 높이 유지)
- Ctrl+휠 확대·축소, macOS에서는 ⌘+휠도 지원. 수식키 없는 휠은 스크롤
- 연속 핀치 확대·축소: 손가락 중심점을 유지하고 제스처 종료 후 선명한 페이지로 갱신
- 활성 PDF의 내장 목차·페이지 썸네일을 전환하는 Document 패널
- PDF 스크롤바 전용 여백·넓은 드래그 영역, 캡처 이동 시 부드러운 스크롤·테두리 등장·300ms 페이드아웃
- Captures의 Saved/Trash 전환·개별 복원: 이미지·원문 텍스트·노트·워크스페이스 연결 유지 ([사용법](docs/CAPTURE_TRASH.md))
- 영역 캡처 저장 및 원문 위치로 돌아가기
- 선택 문장을 텍스트 캡처로 저장, 전체 문장 읽기·복사·검색·원문 이동
- 캡처 원본의 SHA-256 검증: 파일이 바뀌면 잘못된 출처로 이동하지 않도록 중단
- 최근 문서, 창 구성과 읽던 위치 보존 (앱은 항상 Home으로 시작)
- 최근 파일 목록에서 제거, 캡처를 로컬 휴지통으로 삭제
- 검색 `⌘/Ctrl+K`, 명령 전용 팔레트 `⌘/Ctrl+Shift+P`, 명령 이름의 일치 부분 강조
- 영어 UI, 닫거나 좌우로 이동할 수 있는 Files / Captures / Document 패널
- 선택한 폴더의 PDF·하위 폴더 탐색 (읽기 전용, 펼칠 때 비동기로 불러오기)

## 패널 사용

- 패널과 본문 사이 경계를 좌우로 드래그하면 너비를 조절할 수 있습니다. 좌우 너비는 각각 저장하며 창 크기에 맞춰 제한합니다.
- 하단 상태 표시줄의 폴더/그림/문서 아이콘으로 Files / Captures / Document를 열거나 닫습니다. 아이콘 위에 잠시 머무르면 설명이 표시됩니다. 패널의 별도 닫기 버튼은 없습니다.
- 아이콘을 **우클릭 → Left Dock / Right Dock**으로 위치를 정합니다. 아이콘 드래그는 제거했습니다.
- 닫힌 패널도 위치를 변경할 수 있고 닫힌 상태를 유지합니다. 여러 패널이 같은 쪽이면 아이콘이나 제목 탭으로 전환하고, 활성 패널의 아이콘을 다시 누르면 닫힙니다.
- `Files`는 처음에는 최근 PDF를 표시합니다. `Open folder…`로 폴더를 선택하면 하위 폴더와 PDF 목록을 표시합니다. `↻`로 새로 고칩니다.
- 원본 파일은 변경하지 않으며, 숨김 파일·심볼릭 링크는 목록에서 제외합니다. 파일 생성·이동·삭제 기능과 폴더 전체 본문 검색은 아직 없습니다.
- 패널의 위치·열림 상태·선택한 루트 폴더는 재실행 시 복원합니다. 하위 폴더의 펼침 상태는 아직 저장하지 않습니다.

## PDF 목차·썸네일

- 하단 문서 아이콘 → Document 패널에서 **Outline / Thumbnails**를 선택합니다. 선택 모드도 저장합니다.
- Outline은 PDF에 내장된 목차를 계층으로 표시합니다. 항목을 누르면 해당 페이지·위치로 이동합니다. 목차가 없는 PDF는 안내를 표시하며, 본문에서 목차를 자동 생성하지는 않습니다.
- Outline/Thumbnails의 선택된 탭은 더 어두운 회색, 선택되지 않은 탭은 밝은 회색입니다.
- Thumbnails에서 페이지 미리보기를 눌러 이동합니다. 현재 페이지를 테두리로 표시하며, 보이는 범위 주변의 저해상도 미리보기만 생성합니다.
- 패널은 현재 활성 탭·분할을 따라갑니다. 리더와 PDF 문서 객체를 공유합니다. Home에서는 문서를 열라는 안내가 나옵니다.

## 문서 탭·분할

- PDF를 열면 활성 그룹에 탭이 추가됩니다. 같은 그룹에 이미 열린 원본이면 해당 탭을 선택합니다. 비활성 탭은 상태만 보존하고 각 그룹의 활성 문서만 PDF 리더에 로드합니다.
- `⌘/Ctrl+W`, 탭의 `×`, 가운데 버튼 클릭, 탭 우클릭 → Close Tab으로 닫습니다. 원본 PDF·최근 목록은 유지합니다. 마지막 탭을 닫으면 Home으로 돌아갑니다.
- `⌘/Ctrl+T`는 현재 그룹에 독립된 Home 탭을 만듭니다. 여기서 새 PDF를 열면 해당 Home 탭을 PDF 탭으로 바꾸며, 이미 열린 PDF는 기존 탭을 재사용합니다. Home 탭도 닫기·다시 열기·이동·분할·세션 복원이 가능합니다. 앱 시작은 기존처럼 전체 Home 화면입니다.
- 탭 줄 오른쪽 `+`를 클릭해도 해당 그룹에 새 Home 탭을 만듭니다.
- 탭을 다른 그룹 **중앙**에 놓으면 이동, **좌/우/상/하 가장자리**에 놓으면 분할합니다. 탭 표시줄에서는 순서를 바꿉니다. 드롭 위치가 회색으로 표시되며 Esc/영역 밖 드롭은 취소합니다.
- 같은 그룹의 유일한 탭을 가장자리로 끌면 분할하지 않습니다. 같은 논문을 나란히 보려면 탭 우클릭 → **Duplicate to Right Split / Duplicate to Bottom Split** 또는 View 메뉴를 사용하세요. 각 복제 탭의 페이지·배율은 독립적입니다.
- 하단 분할 아이콘은 활성 탭을 오른쪽 분할로 복제합니다. 명령 팔레트의 `Split: Duplicate Tab Right` / `Split: Duplicate Tab Below`도 같습니다.
- 빈 그룹은 제거되고 분할 트리가 축약됩니다. View → Join All Groups 또는 명령 `Split: Join All Groups`는 탭을 잃지 않고 한 그룹으로 합칩니다.
- 분할 경계를 드래그해 크기를 조절합니다. 그룹의 최소 크기(440×280)를 유지하며, 화면보다 커지면 바깥 작업 영역의 스크롤바로 이동합니다. 실제 사용 가능한 분할 수는 메모리·화면 제약을 받습니다.
- `⌘/Ctrl+Shift+T` 또는 `Tab: Reopen Closed Tab`으로 닫은 탭의 위치·배율을 복원합니다. 현재 실행·워크스페이스에서 최근 20개까지 기억하며 재실행·워크스페이스 전환 시 기록을 비웁니다. 기존 그룹이 없어지면 활성 그룹에 엽니다.
- OS 별도 창으로 탭 떼어내기와 드래그 중 가장자리 자동 스크롤은 아직 없습니다.

## 목록 제거·캡처 삭제

- Home의 Recent Papers 또는 Files의 Recent files에서 항목을 우클릭 → **Remove from Recent Papers…** → 확인. 원본 PDF, 열린 탭, 읽기 위치, 워크스페이스 연결, 캡처는 유지합니다. PDF를 다시 열면 최근 목록에 다시 등록됩니다.
- 선택한 실제 폴더 트리는 파일시스템을 그대로 보여주는 읽기 전용 탐색기입니다. 최근 목록 제거와 원본 파일 삭제는 다르며 원본 삭제 기능은 제공하지 않습니다.
- 캡처의 `…` 또는 우클릭 → 붉은색 **Delete** → 확인. 취소하면 그대로 유지됩니다. 삭제한 캡처는 검색·목록·원문 열기에서 제외하고 이미지는 데이터 폴더의 `captures/trash/`로 옮깁니다. 원본 PDF는 건드리지 않습니다.
- 텍스트 캡처도 같은 방식으로 삭제하며, 원문 텍스트와 출처는 DB에 삭제 표식과 함께 보존합니다. 복원 UI는 후속 작업입니다.

## 텍스트 캡처

- 문장을 드래그한 뒤 리더의 **Save excerpt**, 또는 명령 팔레트의 **Capture: Save Selected Text**를 실행합니다. 저장하면 Captures 패널이 열립니다.
- 카드 클릭은 원문 위치로 이동합니다. `…` / 우클릭 → **Read Excerpt…**에서 긴 문장을 읽고, **Copy Text**로 저장한 원문 전체를 복사합니다.
- Home / `⌘/Ctrl+K`에서 저장한 문장 내용도 검색합니다. 캡처 문장은 대소문자를 구분하지 않는 부분 문자열 검색이며, PDF 본문의 단어 접두어 검색과는 다릅니다.
- 파일이 없어지거나 변경되어도 저장한 문장은 남습니다. 원본 이동은 동일 파일로 재연결하고, 다른 버전으로의 자동 이동은 하지 않습니다.
- 한 페이지 안의 선택만 지원합니다. OCR·수식/2단 읽기 순서 교정·영구 하이라이트·메모는 아직 없습니다. [저장·검증 범위](docs/TEXT_CAPTURES.md).
- 삭제 기록은 DB에 보존되어 수동 복구 여지는 남아 있습니다. 휴지통 복원·영구 비우기 UI는 후속 작업입니다. OS 휴지통과는 다릅니다.

## Home 사용

- 앱은 항상 Home으로 시작합니다. 이전 탭과 분할은 보존하되 리더의 PDF 로드·렌더링은 Continue Reading 등으로 읽기를 시작할 때 수행합니다. 본문 인덱싱은 Home에서도 별도 백그라운드 작업으로 PDF를 읽을 수 있습니다. 하단 집 아이콘은 제거했습니다. 필요할 때 View → Home, `⌘/Ctrl+Shift+H`, 명령 `View: Go to Home`으로 돌아갈 수 있습니다.
- 중앙 검색은 앱에서 연 PDF의 **본문·파일명**, 저장한 캡처의 **문장 내용·출처 파일명·페이지**, **워크스페이스 이름**을 찾습니다. 본문 결과에는 문맥·페이지를 표시하고 클릭 또는 방향키·Enter로 원문 페이지를 엽니다. 폴더 전체 PDF를 자동 등록하지는 않습니다.
- Continue Reading은 마지막 활성 문서의 페이지·스크롤·배율을 복원합니다. 최근 PDF도 개별 읽기 위치를 기억합니다.
- Recent Workspaces 옆 `+`로 이름을 지정해 만듭니다. 항목 오른쪽 `…` 또는 하단 `Workspace…`에서 전체 문서·캡처 연결, 이름 변경·삭제를 관리합니다. Unlink는 원본·캡처·노트·열린 탭을 유지하며, 명시적으로 해제한 문서는 자동 저장으로 다시 연결되지 않습니다. [워크스페이스 관리](docs/WORKSPACES.md).
- Recent Papers는 최근 12개, Recent Workspaces는 최근 12개를 표시합니다. 이름 검색은 이 최근 표시 개수 밖의 저장된 항목도 찾습니다(종류별 최대 20개 결과). 본문은 논문별 3개 미리보기이며 더 보기로 확장합니다.
- 네이티브 다중 창과 새 창 전용 Home 흐름은 아직 없습니다. 같은 데이터 폴더를 여러 앱 인스턴스에서 동시에 열지 마세요.

## 검색과 명령 팔레트

- **검색 `⌘/Ctrl+K`**: Home과 같은 PDF 본문·파일명·캡처 문장/출처·워크스페이스 이름 검색입니다. 빈 입력에는 최근 PDF가 나옵니다.
- **명령 `⌘/Ctrl+Shift+P`**: 실행할 기능만 찾습니다. 슬래시 명령과 설명을 따로 표시하지 않고 `File: Open PDF`, `Split: Duplicate Tab Right`, `Capture: Select a Region` 같은 하나의 이름을 사용합니다.
- 대소문자 구분 없이 이름에 포함된 문자열을 찾고 일치 부분을 낮은 채도의 파란색으로 강조합니다. 공백으로 나눈 여러 검색어는 모두 포함되어야 합니다. 예: `dupli right` → `Split: Duplicate Tab Right`.
- `Capture: Select a Region`은 새 영역 캡처 모드, `Panel: Toggle Captures`는 저장된 캡처 목록입니다. 기존 `/...` 입력 방식은 제거했습니다.
- 방향키·Enter로 선택하고 Esc로 닫습니다. 현재 PDF가 필요한 기능은 PDF가 없으면 비활성화합니다.

핀치 중에는 기존 페이지 이미지를 연속 확대·축소하고, 종료 후 최종 배율로 렌더링합니다. 새 이미지가 준비되는 동안 기존 이미지를 유지합니다. 실제 macOS 트랙패드의 체감 부드러움·Windows/Linux 입력은 수동 검증이 남아 있습니다. 휠 확대는 앱에 이벤트가 전달될 때 동작하며, macOS의 Command/Control 매핑은 [Qt 플랫폼 문서](https://doc.qt.io/qt-6/qt.html#KeyboardModifier-enum)에 맞춰 처리합니다.

## 본문 검색과 인덱스

- PDF를 열면 백그라운드에서 페이지별 텍스트를 추출합니다. 기존 최근 문서·읽기 위치·워크스페이스의 문서도 첫 실행에 등록합니다. 원본이나 외부 서비스는 수정하지 않습니다.
- 본문은 단어 접두어 검색이며 입력한 단어가 모두 같은 페이지에 있어야 합니다. 예: `counter evidence`. 논문당 관련도 상위 3페이지를 먼저 표시하고, 한 번에 20개 논문씩 제공합니다. `More papers`로 다음 묶음을 볼 수 있습니다.
- 논문 제목 행 / `Show all 12 matching pages in '파일명.pdf'`를 누르면 그 논문만 40페이지 단위로 검색합니다. `Back`으로 돌아가며 검색어를 유지합니다. 개수는 단어 출현 횟수가 아니라 일치 페이지 수입니다.
- `Filters`에서 PDF text / File names / Captures와 특정 논문을 선택합니다. 리더에서 연 Cmd+K에는 `Current PDF`도 있습니다. `Clear filters`로 해제합니다. 실제 논문 제목·저자·연도 필터와 문장 정확 일치·의미 검색은 아직 없습니다.
- 검색창 아래 `Text index`를 누르면 진행 상태, Pause/Resume, 실패 문서 Retry를 볼 수 있습니다. 스캔·암호 PDF는 이유를 표시하며 OCR·암호 본문 인덱싱은 아직 없습니다.
- 결과를 열 때 원본 SHA-256을 확인합니다. 변경·유실되었으면 이동을 차단하고 인덱스를 갱신합니다. 기존 탭을 재사용하며 정확한 페이지로 이동하지만 문장 좌표 강조는 아직 없습니다.
- `Remove from Recent Papers`는 최근 목록에서만 제거합니다. 이미 인덱싱한 본문은 검색에 남습니다. 검색 대상에서 제외하는 기능은 후속 단계입니다.
- 추출한 본문은 데이터 폴더의 `search.sqlite3`에 암호화 없이 로컬 저장합니다. 검색 규칙·안전장치·한계는 [본문 검색 설명](docs/SEARCH.md)을 참고하세요.

## 원본 PDF 재연결

옮겨진 파일은 최근 파일/캡처 우클릭 → **Locate Original PDF…** → 새 파일 선택 → **Verify and Relink**로 연결합니다. 같은 SHA-256일 때만 처리하며 원본 PDF를 이동하거나 삭제하지 않습니다. 검색 상태 창의 Locate…와 문서 열기 오류 화면에서도 사용할 수 있습니다. [재연결 사용법·안전장치](docs/RELINK.md)를 참고하세요.

## 빌드와 테스트

C++20, CMake 3.24 이상, Qt 6.9 이상이 필요합니다. 현재 macOS에서 Qt 6.11.2로 빌드·테스트합니다.

```sh
brew install cmake qtbase qtdeclarative qtwebengine
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug -DCMAKE_PREFIX_PATH=/opt/homebrew
cmake --build build --parallel 6
ctest --test-dir build --output-on-failure
```

Qt PDF는 Homebrew의 `qtwebengine`에 포함됩니다. 현재 앱은 PDF 모듈을 사용하며, 웹 브라우저는 아직 구현하지 않았습니다. Intel Mac이나 다른 OS에서는 Qt 설치 경로를 맞춰야 합니다. Linux/Windows의 실제 실행은 아직 검증하지 않았습니다.

테스트는 임시 PDF와 데이터 폴더를 만들고, 데스크톱 조작 없이 offscreen Qt 창에서 실행합니다. 저장·출처 검증, PDF 렌더링·선택·복사, 줄 높이, 검색·위치 복원, 분리된 팔레트와 일치 강조, 중첩 목차·썸네일 이동, 패널 복원, 폴더 탐색, Home 지연 로드, 탭 닫기·다시 열기, 분할·드래그, 삭제·원본 보존을 검사합니다. 합성 네이티브 핀치 이벤트·중심점·렌더 해상도 유지도 검사합니다. 합성 PDF 성능 기준과 한계는 [PERFORMANCE.md](docs/PERFORMANCE.md)에 기록합니다. 테스트 통과가 실제 장치에서의 사용성 검증을 대신하지는 않습니다.

## 데이터와 한계

지정한 데이터 폴더의 `owelk.sqlite3`에 세션·문서별 위치·워크스페이스·캡처 출처/문장·재연결 기록을, `captures/`에 영역 PNG를 저장합니다. 원본 PDF는 복사하거나 수정하지 않고 경로로 참조합니다. 원본을 이동하면 새 파일을 사용자가 선택하고 동일성을 검증해 재연결합니다. 자동 파일 탐색은 없으며 저장된 캡처 이미지·문장은 유지됩니다. 로컬 저장 데이터는 암호화하지 않습니다.

세션 형식은 버전 2의 탭 그룹·분할 트리입니다. 기존 버전 1의 두 문서 세션/워크스페이스는 열 때 변환하며 숨겨져 있던 오른쪽 문서도 보존합니다. 알 수 없거나 잘못된 버전 2 레이아웃이면 복원을 중단하고 해당 저장 데이터를 덮어쓰지 않습니다.

캡처 카드의 `Add note` / `Edit note`에서 원문과 별도로 메모를 작성하고 `Save`로 저장합니다. 노트도 Home/Cmd+K 검색에 포함되고, `Delete note`는 원문 캡처를 유지합니다. [노트 범위와 저장 방식](docs/CAPTURE_NOTES.md).

문장 선택 후 떠 있는 도구의 Highlight로 줄별 하이라이트를 저장합니다. 재실행 후 유지되며 Cmd+K 검색과 우클릭 Remove Highlight를 지원합니다. 원본 PDF는 변경하지 않습니다. [하이라이트 사용법](docs/HIGHLIGHTS.md).

현재 API 호출·로그인·외부 업로드는 없습니다. PDF의 웹 링크를 누르면 시스템 브라우저에서 열립니다. AI, 웹 탭, OCR, 독립 노트, 백업 UI는 아직 미구현입니다. 여러 페이지를 가로지르는 텍스트 선택과 암호 PDF의 영역 캡처도 아직 지원하지 않습니다.

## 이어서 할 작업

1. 읽기 품질 실기기 확인: 핀치 체감, 실제 대형 PDF·다중 분할의 지연·메모리 측정
2. 본문 검색 실사용 검증: 실제 논문의 추출 품질, 묶기·필터·더 보기 사용성, 인덱스에서 문서 제외
3. 탭 탐색 단축키·활성 그룹 자동 노출, 워크스페이스 범위 검색
4. 삭제 워크스페이스 복원 UI, 이후 AI 읽기 보조와 웹 읽기

문서 탭·분할 트리·탭 드래그 분할 묶음은 구현했습니다. 다음 작업의 검증 조건은 [개발 작업 목록](docs/NEXT.md)에 기록합니다. UI 번역 설정은 후속 작업이며 현재 인터페이스는 영어입니다.

불필요한 상단 앱 이름 바는 제거했고, 기본 탐색·패널 조작은 하단 상태 표시줄로 모았습니다. 기획서와 구현의 차이는 [진행 현황](docs/STATUS.md)을 참고하세요.
